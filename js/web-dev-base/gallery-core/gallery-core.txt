gallery-core.js (`js/web-dev-base/gallery-core/`)

Constants: STAGING_GALLERY_NAV_STORAGE_KEY, STAGING_GALLERY_ACTIVATE_STORAGE_KEY, STAGING_GALLERY_SCROLL_STORAGE_KEY, STAGING_GALLERY_SETTINGS_EVENT, stagingGalleryPrefsStorageKey(id), publishedGalleryPrefsStorageKey(id), stagingGalleryPanelPosStorageKey(id) — staging session overrides + **published** live prefs in `localStorage`; `window` event (`detail.galleryStorageId`) for live updates; prefs JSON includes `stripClickAction` / `stripDblclickAction` / `stripContextmenuAction` (`toggle_zoom` | `select_only` | `none`). Also DEFAULT_STRIP_IMAGE_SIZES, DEFAULT_ZOOM_IMAGE_SIZES, DEFAULT_LIGHTBOX_IMAGE_SIZES — default `sizes` for draggable strip, zoom pane, and gallery lightbox (phone vs laptop breakpoints).

buildSrcsetSuffixWidths(src, widths[]) — optional helper: builds `srcset` with `-{w}` before extension; files must exist at those URLs.

normalizeImageEntry — string or rich object → normalized fields:
  - string → src only, rest empty/undefined
  - object: src, alt?, srcset?, sizes?, fullSrc?, fullSrcset?, fullSizes?, loading?, fetchPriority?
  Strip `img` uses src/srcset/sizes; zoom pane prefers fullSrc / fullSrcset / fullSizes (data attributes on the slide img) else falls back to strip src/srcset and gallery zoomImageSizes.

wrapGalleryIndex — circular index for prev/next

setGalleryBodyScrollLocked — true = hide body scroll (lightbox)

bindDocumentGalleryKeydown — Escape / arrows when open; returns dispose()

initGalleryLightboxFromDom — hooks .gallery-item + #lightbox when present; lightbox `src` from `data-full`, `srcset` from `data-full-srcset` on the button, else `data-full-srcset` on the thumb img, else thumb `srcset`; `sizes` = DEFAULT_LIGHTBOX_IMAGE_SIZES; clears srcset/sizes on close.

createDraggableGallery(root, options?) — strip + zoom on wide viewports; at max-width 900px zoom UI is hidden and open-zoom is no-op; when staging, **Click** / **Double-click** / **Right-click** on strip thumbnails each get an assignment (open/toggle zoom, select thumb only without zoom, or no action; at least one gesture must stay usable); setImages, addImages, clear, destroy; goPrev / goNext (step ±1 passed into zoom so bookflip direction matches the control when the strip wraps); zoomThumbFill; zoomPaneMaxHeight (CSS string for --draggable-gallery-zoom-pane-max); stripImageSizes, zoomImageSizes override defaults; stripHalfClickNav (default true); stagingGalleryToolbar (default true when html has class staging): dotted frame + **“Gallery testing”** label on **that gallery** toggles a draggable floating panel (per-root `id` or `data-staging-gallery-storage-id`); prefs JSON in session while staging + **Save & publish to live** → `localStorage` `customdev_gallery_prefs_published_<id>` for the same id on **live** loads; panel position keys; legacy flat session keys read if JSON missing. First slide: loading eager, fetchPriority high; others lazy / auto unless overridden per image. **Zoom shell:** enter/exit animation from `zoomOpenAnim` (`none` | `slide` | `fade` | `scale`, staging dropdown **Zoom open/close**). **Zoom image change** while zoom stays open: `slideTransition` (`none` | `crossfade` | `bookflip`). **Book flip:** one visual stage — absolute **left / right** halves over a full-area **under** layer clipped to the right half; left/under/front images share one **registration** (same centered `object-fit: contain` rect as a single full zoom image, then clip/mask), not independent half crops. **`zoom-book-under`** holds the next (or incoming) image at **full** size with that clip; at rest **`opacity: 0`** so transparent PNGs do not show the next slide on the left. While `.draggable-gallery__zoom--bookflip-running`, **under** opacity fades in on a **delayed** transition (spread vars `--draggable-gallery-bookflip-under-fade-delay-frac` / `…-dur-frac`) so the reveal ramps **mid flip** through completion; when the class is removed, under snaps off (no fade-out). The leaf’s paper **back** is hidden during the turn; **front** `drop-shadow` applies **only** while turning (none at rest). **Next** animates `.draggable-gallery__zoom-book-flipper--right` with `--turn-book-next` and fades **`.draggable-gallery__zoom-book-under`** (right clip). **Prev** animates **`.draggable-gallery__zoom-book-flipper--left`** at the gutter (`transform-origin: right center`) with `--turn-book-prev`, shows **`.draggable-gallery__zoom-book-right-static`**, and fades **`.draggable-gallery__zoom-book-under-prev`** (left clip); `zoom--bookflip-dir-prev` selects that path. `runBookflipImageSwap` resets whichever flipper ran, then `applySrc()`. **Crossfade / non-book:** zoom spread enforces pane `min-height` and the flipper stays `position: absolute` so the zoom image is not height-collapsed. **First slide:** the first strip thumb uses `object-position: left` (horizontal strip when zoom closed, and the zoom-open rail); when that slide is active and zoom is open, the zoom column uses `justify-content` / `align-items: flex-start` and (non-book) the main `zoom-image` uses `object-position: left` (`:has(.draggable-gallery__slide:first-child.is-active)` on the root). **Close:** default exit transition unless `zoomOpenAnim` is `none` / reduced motion / `closeZoom({ immediate: true })`.

runBookflipImageSwap(flipperEl, zoomAside, direction, applySrc, onDone?) — exported helper: animates **right** flipper + `--turn-book-next` when `direction >= 0`, or **left** flipper + `--turn-book-prev` when `direction < 0` (also sets `zoom--bookflip-dir-prev`); transform reset then `applySrc()`; returns cancel. **Book halves:** the turning side uses `zoom-book-under` / `zoom-book-under-prev` (fade in from flip start over `--draggable-gallery-bookflip-dur`); the static side uses stacked imgs (`--left` + `--left-incoming`, `--right-static` + `--right-static-incoming`) to crossfade the other half in the same window. runCrossfadeImageSwap(zoomImg, applySrc, onDone?) — opacity classes plus **timed** out/in phases (~240ms / ~300ms) so the swap always completes even when `prefers-reduced-motion` sets `transition: none` on `.draggable-gallery__zoom-image`; returns cancel. **GALLERY_BOOKFLIP_MS** — turn duration (ms). **GALLERY_BOOKFLIP_HALF_MS** — deprecated alias of `GALLERY_BOOKFLIP_MS`.
